# 影视目录归档

整理源网站的电影和剧集条目，并在源网站不再提供某条目时保留已有归档。

## Language

**站内条目**：源网站的一篇内容记录，可能对应一部电影、一季电视剧或一个合集；不等同于一部去重后的影视作品。
_Avoid_: 把所有条目统称为“电影”或“单集”

**站内 ID**：源网站分配给条目的标识。同一部剧的不同季如果分属不同条目，就有不同的站内 ID。

**资源版本**：同一条目下的一种发行或压制版本，具有自己的名称、画质、音轨、字幕和文件大小等说明。
_Avoid_: 用“影片”同时指作品和资源版本

**封面**：用于识别条目的海报图片，与电影或剧集的视频内容不同。

**浏览分类**：影库中的电影、剧集两个目录。同一站内条目可以在两个分类中分别出现；分类数量不等同于去重后的作品数量。

**本地保留条目**：已经归档、但当前源网站未再返回的条目。源网站缺失不意味着应从本地删除。

**仅新增归档**：只收录本地目录尚未包含的站内条目；已有条目的影视资料保持为首次收录时的快照。

**重建归档**：以源网站当前可取得的条目重新形成目录。已从源网站撤下的条目可能无法再次取得。

**历史资源**：之前出现在条目中、后来未在来源页面再次出现的资源版本；仍然属于本地归档的一部分。

**封面版本**：同一站内条目在不同时间使用的不同封面图片。更换封面不改变条目的身份。

**蓝光原盘分类**：来源网站按发行资源形式设置的独立分类，不是电影题材；其条目也可能是演唱会等非电影内容。
